# M3 子项目 C：快捷键自定义 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 13 个应用动作可在“快捷键设置…”模态中录制/清除/重置，覆盖存 `config.toml` 的 `[keymap]`；全局快捷键按生效表分发；非法/冲突被拒绝。

**Architecture:** 后端 `app/src-tauri/src/keymap.rs`（`read_keymap`/`set_binding`/`reset_keymap` 纯函数 + 3 命令，复用 `config_path`）；前端 `keymap.ts`（`DEFAULT_BINDINGS`、`eventToAccel`、`parse/format`、`validate`、`mergeBindings`、`conflictOf`）+ `keymap-ui.ts`（录制模态）；`main.ts` 抽 `ACTION_DEFS`（id/title/run）供面板与分发共用，`registerShortcuts` 查表分发。

**Tech Stack:** Rust（复用 `toml`）+ TypeScript。门：`cargo test` / `cargo clippy --workspace --all-targets -- -D warnings` / `npm --prefix app/frontend test` / `run build`。

**Spec:** `docs/specs/2026-10-25-m3-keymap-design.md`。承接：命令面板 `buildCommands`（`Command{id,title,hint?,run}`）、`config_path` + `toml`、jsdom（仅 DOM 用例）。

## Global Constraints

- 动作表 13 项（open/save/save-as/query/jump/palette/close/sidebar/inspector/can-panel/can-import/can-parse/can-snippet）；默认键见 spec §2。
- 加速键规范：修饰顺序 `Ctrl+Alt+Shift+Key`；`Ctrl` 匹配 Ctrl/Cmd；`validate` 必须含 Ctrl/Alt 或 `F1..F24`。
- 存储：`config.toml` `[keymap]`；缺失→默认；`""`→解绑；`set_binding(None)`→删键回默认；保留其它配置键。
- 冲突先到先得（后者从分发表剔除并记录）；录制重复键直接拒绝。
- F3/Shift+F3 与 CodeMirror 内建键位（Ctrl+F 等）保持固定、不进 `[keymap]`。
- 简体中文 UI；逐任务 TDD；四门绿再提交；commit 前追加 CHANGELOG；commit 消息无空格；commit 后 push；分支 `--no-ff` 合 `main`。
- 分支基：从 `main`（当前 `9ac6c43`）新建 `feat/m3-keymap`。

## Review Focus

1. **配置写回保真**：`set_binding`/`reset_keymap` 保留 `recovery_enabled`、`theme` 等其它键；`None` 与 `""` 语义区分正确；坏 TOML 重建不丢恢复开关（重要：重建只能发生在本就解析失败的文本上）。
2. **校验防劫持**：裸字母/Escape/Enter/Tab/Space/Backspace/Delete 拒绝；`F3`、`Ctrl+Shift+F`、`Alt+1` 通过；仅修饰键 `eventToAccel` 返回 null。
3. **合并与冲突**：默认→覆盖→`""` 解绑顺序；同一 accel 两个动作先到先得；未知 id 忽略并上报；`Ctrl` 与 Cmd 命中同一 accel。
4. **分发正确性**：新键生效且旧键失效；F3 分支仍优先且不被自定义表影响；`Ctrl+F` 未绑定时不被 preventDefault（CodeMirror 搜索不受损）。
5. **模态隔离**：打开期间全局分发短路；录制时按下的键不进编辑器；Esc 取消不落盘；冲突红字指向占用动作；关闭后立即生效。
6. **失败安全**：`keymap_set/reset` 写盘失败 → toast + 内存保持旧表；启动读取失败 → 全默认 + 提示一次。

## 备注：接缝/决策
- `ACTION_DEFS` 是唯一动作源：面板、分发、模态列表都从它取；`theme-*` 等非绑定命令仍只存在于面板。
- `keymapState` 唯一真源（模块变量）；每次写盘成功后重算，键盘分发用最新值。
- `Ctrl` token 统一匹配 Ctrl/Cmd（`eventToAccel` 里 `ctrlKey||metaKey`）。
- modal 打开时 `registerShortcuts` 短路，录制 keydown 在 overlay 捕获阶段 `preventDefault/stopPropagation`。
- `F3`/`Shift+F3` 分支保持在最前、不可覆盖；`Ctrl+F` 不绑定 → 不 preventDefault，CodeMirror 搜索照常。
- 写盘失败不回滚用户已看到的输入？— **定案**：失败 toast 且内存不改（行仍显示旧键），下次操作重试。
